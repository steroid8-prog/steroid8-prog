## Привет! Мы — PlayLabs 👋

Создаём приложения для повседневных задач: подключения к VPN, наблюдения за криптовалютным рынком и удобного использования телевизора. Разные направления объединяет одна идея — понятные инструменты, которыми удобно пользоваться каждый день.

Развиваем проекты постепенно, проверяем идеи на практике и дорабатываем приложения с учётом обратной связи.

## Наши проекты

| Проект | Для чего |
| :--- | :--- |
| **🔐 PlayVPN** | Приложение для подключения к VPN и управления соединением. |
| **📺 PlayVPN TV** | VPN-приложение для телевизора с интерфейсом для большого экрана и управления пультом. |
| **📊 Криптовалютный скринер** | Инструмент для обзора криптовалютного рынка и поиска интересующих монет по выбранным параметрам. |
| **🏠 Лаунчер для Android TV** | Собственный главный экран телевизора с удобным доступом к приложениям и управлением пультом. |
